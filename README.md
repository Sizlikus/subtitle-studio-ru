# Subtitle Studio RU

Веб-приложение для перевода `.srt` и `.ass` с английского и китайского на русский через OpenAI.

## Что умеет

- SRT и ASS; таймкоды и структура файла сохраняются локальным парсером.
- ASS/HTML-теги и переносы защищаются плейсхолдерами до отправки в модель.
- Автоопределение EN/ZH или ручной выбор языка.
- Режимы: «для озвучки», «нейтрально», «кратко под тайминг».
- Пользовательский глоссарий имён и терминов.
- Quality mode: GPT-5.6 Luna делает перевод, GPT-5.6 Sol выполняет редакторскую вычитку.
- Контекст предыдущих реплик передаётся между пакетами для лучшей связности.
- Индикатор знаков/сек для быстрой ручной проверки длинных фраз.
- Ограничение API: 8 запросов/мин на IP+домен.
- Файл разбирается в браузере; на сервер отправляется только текст реплик и минимальный контекст.
- UTF-8, с автоматическим fallback на GB18030 при повреждённом китайском тексте.

## Netlify

Статический фронтенд находится в `public/`, функция перевода — `netlify/functions/translate.mts`.
AI вызывается через Netlify AI Gateway и официальный SDK OpenAI. В обычной конфигурации отдельный API-ключ OpenAI в коде не нужен.

После production deploy AI Gateway становится доступен для проекта. Убедитесь, что AI features не отключены в настройках команды Netlify.

## Проверка

```bash
npm install
npm run check
```

Тесты проверяют SRT round-trip, ASS с запятыми в поле Text, сохранение служебных тегов и расчёт темпа.
